# DeckWare support

Help and feedback for **DeckWare**, the card scanner, collection tracker and deck builder for Cyberpunk TCG players, on iPhone and Android.

- **Found a bug?** Open an [issue](../../issues/new/choose) with the bug report template.
- **Have an idea or a question?** Start a [discussion](../../discussions).
- **Something private,** such as a purchase problem? Email **support@reventi.se**.

Please don't post anything personal in issues or discussions. They're public.

[Privacy policy](https://gist.github.com/facit/29d65d981111769cd691d5353cafdbbf)
